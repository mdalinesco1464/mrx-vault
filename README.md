# 🔒 MRX-VAULT
A lightweight, self-hosted, zero-trust local password manager built with **Python Flask**, **7-Zip (AES-256)**, and **Git**.

## Features
- **Master Password with vault lock and unlock
- **Credential add/search/copy and clipboard copy
- **Create Encrypted Backup and Restore Test
## Prequisities & Dependencies 
- **Python 3.x** and Flask Fremwork with virtual environment
- **7-Zip bineries(7z.exe and 7z.dll) ** included in the project directory for handeling AES-256 encrypted backups.
